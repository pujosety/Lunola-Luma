# Lunola Luma 0.8.2 — Partial Preview

> Published as a GitHub prerelease: [Lunola Luma v0.8.2](https://github.com/pujosety/Lunola-Luma/releases/tag/v0.8.2). The tag points to main commit `9da31de69a84f160f7f4634c4929387c5e8cf0d6`.

This is an incomplete preview, not a stable release. The upstream update includes Krita `.kra`/`.krz` read-only import and the accompanying editing, file-format, UI, performance, and security improvements.

## Included downloads

- **Windows x64:** MSI installer and portable ZIP. Both are unsigned; the ZIP contains unsigned executables.
- **Linux x86_64 and aarch64:** AppImage, zsync metadata, DEB, RPM, and tar.gz for each architecture.
- **Flatpak:** x86_64 and aarch64.
- **Checksums:** `SHA256SUMS.txt` for all 14 package files. Each manifest digest was checked against GitHub's asset digest.

The release contains 15 uploaded assets total: 14 package files and the checksum manifest.

## Not included

macOS, Linux riscv64, WebAssembly, Windows x86/ARM64, and FreeBSD packages are unavailable in this preview.

## Verification and known issues at the release tag

- At tag commit `9da31de69a84f160f7f4634c4929387c5e8cf0d6`, CI reported failures in corpus tests, the wasm32 check, and the WebAssembly build/size gate. Packaging lint also failed in its run on that commit.
- The local workspace test command at that tag exited with code 101: **27 CLI integration tests passed, 1 failed**. `usage_and_unknown_command` expected the version output to start with `photocraft-cli `.
- The full release workflow could not produce signed Windows packages or a macOS build. The Windows x64 packages included here are unsigned.

## Post-release validation update

The CLI test failure was a stale assertion for the old binary name; the CLI itself prints `Lunola Luma CLI`. The test expectation was corrected in [main commit `70dfb7fb`](https://github.com/pujosety/Lunola-Luma/commit/70dfb7fb9ae8aa1c27d2d06ef55b8cc990e269f3).

After that test-only correction, the focused test passed and the CLI integration suite passed **28/28** on Windows. `cargo fmt --all -- --check` and `git diff --check` also passed.

The correction changes tests only. It does not change the application binaries or release tag; all **15 assets** (14 packages plus `SHA256SUMS.txt`) remain from tag commit `9da31de69a84f160f7f4634c4929387c5e8cf0d6`. The follow-up [GitHub Actions run for `70dfb7fb`](https://github.com/pujosety/Lunola-Luma/actions/runs/38364805570) reported failures in corpus tests, wasm32, the web size gate, and the Ubuntu test; the Windows test was still running at the time of this update. Full CI is not green.

Keep backups of important work and review the missing-platform and test caveats before installing. The previously published [v0.7.0 release](https://github.com/pujosety/Lunola-Luma/releases/tag/v0.7.0) remains available.

## Subsequent CI verification — 2026-10-13

CI remediation is complete on [`main` commit `439a9ef4`](https://github.com/pujosety/Lunola-Luma/commit/439a9ef427a86dfe68d33c71a0919a6758a94839). The [full CI run](https://github.com/pujosety/Lunola-Luma/actions/runs/38381840837) completed successfully: corpus tests, the wasm32 check, web build/size gate, and Ubuntu and Windows test jobs all passed. The conditional fuzz job was skipped. The separate [packaging lint run](https://github.com/pujosety/Lunola-Luma/actions/runs/38373724999) and [documentation build](https://github.com/pujosety/Lunola-Luma/actions/runs/38376997768) also passed.

The remediation added the Linux AppStream homepage, a serial wasm32 tile-hashing path, and an SVG icon test aligned with the current embedded raster icon. It also synchronized the README's 67-tool inventory and supplied the new canvas tagline in every complete-menu translation catalog.

These are source, test, metadata, documentation, and localization updates; they did not rebuild or replace release binaries. The `v0.8.2` tag and its 15 assets (14 packages plus `SHA256SUMS.txt`) remain unchanged. Windows packages remain unsigned and macOS is still unavailable.
