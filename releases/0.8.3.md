# Lunola Luma 0.8.3 — Partial Preview

> This is an incomplete preview, not a stable release. Review the platform availability and signing limitations below before installing.

- **Published:** [Lunola Luma v0.8.3 on GitHub](https://github.com/pujosety/Lunola-Luma/releases/tag/v0.8.3)
- **Tag target:** `67f3154ff3fc44d6c961f4eefbfb0285a8a0f086`
- **Assets:** 24 total (23 package files plus `SHA256SUMS.txt`).

## What changed

- **PSD text-layer re-save:** Drops only the legacy minimal Metrics-only `Txt2` stub when an edited PSD is saved again. Richer Photoshop `Txt2` data and the block needed for Optical kerning are preserved. This targets the narrow case documented in [upstream issue #2469](https://github.com/storytold/photocraft/issues/2469); it does not claim general Photoshop compatibility is complete.
- **Windows ARM64 installer smoke test:** Looks for the installed application in the MSI's actual `Lunola Luma` folder while retaining the compatible executable name `photocraft`.

## Downloads

- **Windows:** MSI installer and portable ZIP for x64, x86, and ARM64.
- **Linux x86_64 and aarch64:** AppImage, zsync metadata, DEB, RPM, and tar.gz.
- **Linux riscv64:** DEB, RPM, and tar.gz.
- **FreeBSD 14 x86_64:** tar.gz.
- **Flatpak:** x86_64 and aarch64 bundles.
- **WebAssembly:** static site ZIP.
- `SHA256SUMS.txt` provides SHA-256 checksums for the package assets.

## Verification

- Version `0.8.3` was built from main commit `67f3154ff3fc44d6c961f4eefbfb0285a8a0f086` by [release workflow run 38555507165](https://github.com/pujosety/Lunola-Luma/actions/runs/38555507165). ## Signing and availability

- Windows installers and executables are unsigned because signing credentials are not configured. Windows may display a security warning.
- No macOS app or CLI package is included. The GitHub-hosted macOS runner was unavailable for this run; there is no macOS build or notarization in this preview.
- This is a partial preview, not a stable release. Verify downloads against `SHA256SUMS.txt` and keep backups of important work.
