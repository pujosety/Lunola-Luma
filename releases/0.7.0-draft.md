# Lunola Luma 0.7.0 — draft record only

> **Not a published release.** `0.7.0` is the current inherited workspace version in `Cargo.toml`; no Lunola Luma tag, installer, signed artifact, or release page has been created. Do not publish these notes as final release notes.

## Candidate summary

- Apply the approved Lunola Luma icon, LUNOLA/LUMA lockup, and visible product naming to the PhotoCraft editor.
- Remove the top-level Help menu; place About under File and keep System Info searchable.
- Remove community/Discord UI controls while retaining required upstream author, copyright, license, and asset attribution.
- Remove the Contributors and Models tabs from About; the product byline and legal upstream attribution remain.
- Preserve existing PhotoCraft package/crate/executable names, document formats and signatures, extensions, MIME/Bundle/registry identifiers, environment variables, upgrade keys, and user-data paths.
