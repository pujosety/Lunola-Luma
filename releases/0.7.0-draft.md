# Lunola Luma 0.7.0 — draft release notes

> **Draft only — not published.** The GitHub 0.7.0 draft exists but remains unpublished pending owner approval. Verified assets, platform coverage, and open release gates are recorded below.

## Candidate summary

- Apply the approved Lunola Luma icon and LUNOLA/LUMA lockup; update the visible product identity to **Lunola Luma by Pujo Setyo**.
- Remove the top-level Help menu; place About under File and keep System Info searchable.
- Remove community/Discord UI controls while retaining required upstream author, copyright, license, and asset attribution.
- Remove the Contributors and Models tabs from About; the product byline and legal upstream attribution remain.
- Preserve stable package/crate/executable names, document formats and signatures, extensions, MIME/Bundle/registry identifiers, environment variables, upgrade keys, and user-data paths for compatibility.
- GitHub has an unpublished 0.7.0 draft with 20 assets: 19 package files from successful CI builds and a verified `SHA256SUMS.txt`. The draft link and exact platform inventory are in [`releases/README.md`](../releases/README.md); no public release is available until an owner publishes it.
- The release tag is not created yet. GitHub creates `v0.7.0` when the draft is published.
- Windows x86/x64/ARM64 MSI and portable executables are unsigned. macOS universal, Linux riscv64, and WebAssembly builds are absent because their CI jobs failed.
- The local optimized Windows build completed, but its version output is marked `(dev build)`; those local binaries are not attached as release assets.

- The Windows GUI smoke test and PNG → `.pcraft` → WebP conversion were previously verified; see [`docs/windows-smoke-test.md`](../docs/windows-smoke-test.md).
- The optimized Windows build of the desktop app and CLI completed successfully with `--features heif`. Both binaries report `0.7.0 (dev build)` and are intentionally not attached.
- [Release workflow run #38238299390](https://github.com/pujosety/Lunola-Luma/actions/runs/38238299390) completed with successful Windows x86/x64/ARM64, Linux x86_64/aarch64, Flatpak x86_64/aarch64, FreeBSD x86_64, and version jobs. macOS universal, Linux riscv64, and WebAssembly failed; the workflow's own draft job was skipped.
- The GitHub draft contains **19 Lunola Luma-named package files plus `SHA256SUMS.txt`** (20 assets total). Uploaded names and sizes were read back from GitHub; GitHub asset SHA256 digests match the staged files.
- ZIP CRCs and tar.gz listings were checked; MSI, DEB, RPM, AppImage and Flatpak file headers were identified. All tested Windows MSI and portable EXE files are **unsigned**.
- The UI library suite recorded **2,184 passed, 1 failed, 10 ignored**. The remaining failure is the known duplicate Czech `"Tool"` catalog key, also present on the recorded baseline. Four targeted Wayland-guidance tests passed.
